# 武器体系、远程战斗与职业武器池

项目：夏叶的异世界冒险（Eternal World）
分支：ew/mobile-first
状态：正式设计规范，待结合上游战斗代码实施和实机验收

## 核心原则

武器体系必须同时支持近战、远程物理攻击和魔法攻击。不同武器不能只换图标和攻击数值，必须有不同的攻击距离、弹道/命中方式、攻击速度、动作、资源消耗、范围和战术定位。

职业与武器采用“职业擅长、其他职业可有限使用”的设计，避免玩家被单一武器锁死；职业专精通过技能、被动和装备适配体现。

## 1. 武器类别

### 近战
- 单手剑：均衡、可搭配盾牌。
- 双手剑：高伤害、较慢攻速、较大攻击范围。
- 短剑/匕首：快攻、暴击、背击或连击。
- 长枪/长矛：直线突刺、较长近战距离、控制距离。
- 斧：高伤害、破甲倾向、较慢攻击。
- 双斧：快速连续攻击、偏近身输出。
- 战锤/钉头锤：对护甲或硬壳目标有优势。
- 棍棒/法杖近战形态：低阶过渡或特殊流派。
- 盾牌：副手防御、格挡、盾击；本身不作为普通主手武器。

### 远程物理
- 短弓：射速快、射程中等、机动性好。
- 长弓：射程远、蓄力更久、单发伤害较高。
- 复合弓：中远程、稳定输出、对力量/敏捷有要求。
- 弩：单发伤害高、装填慢；可扩展轻弩、重弩。
- 投掷飞刀/匕首：短至中距离、快速消耗型。
- 投掷斧/标枪：中距离、重击型，数量或回收规则明确。

远程攻击必须真正生成投射物或使用明确的弹道/命中检测，包含飞行速度、射程、碰撞、命中目标、伤害结算和受阻处理。不能只把近战攻击距离改大。

### 魔法武器
- 木杖/法杖：法术伤害、范围或元素强化。
- 魔杖：快速施法、低消耗或短冷却。
- 奥术书/符文书：技能组合、控制与辅助。
- 圣印/祭器：治疗、护盾、净化和神圣伤害。

魔法武器通过法力消耗、施法前摇、冷却和元素属性形成差异。技能伤害必须接入同一套命中、抗性和伤害结算规则。

## 2. 职业与武器适配

职业不是硬性武器禁用清单，而是专精方向：

- 战士：单手剑+盾、双手剑、斧、锤、长枪；擅长格挡、破甲、近战控制。
- 游侠/弓手：短弓、长弓、复合弓、轻弩、投掷武器；擅长远程、标记、陷阱、移动射击。
- 刺客：匕首、短剑、轻型投掷武器；擅长暴击、背击、快速位移。
- 法师：法杖、魔杖、符文书；擅长元素伤害、范围攻击和控制。
- 牧师/圣职者：圣印、祭器、法杖、单手钝器与盾；擅长治疗、护盾、净化。
- 后续可扩展：召唤师、枪械/火器职业等，但不纳入首个可玩版本的必做范围。

职业专精通过技能树、武器熟练度和被动效果体现。其他职业可以使用部分非专精武器，但不能获得全部专精技能收益。

## 3. 武器必须有真实战斗差异

每个武器模板至少配置：
- 武器类别、手持槽位、适用职业/熟练度。
- 基础攻击力、攻击间隔、攻击前摇/后摇。
- 攻击距离、攻击范围、扇形角度或投射物参数。
- 命中类型：近战碰撞、直线投射物、抛物线投射物、范围法术。
- 资源消耗：法力、弹药、耐久或无消耗。
- 动作动画、音效、命中特效。
- 词条池和可生成品质范围。

弓箭/弩的弹药规则应可配置：基础箭矢可在商店购买或制作；特殊箭矢（火焰、冰霜、穿甲、毒）作为后续扩展。避免首版就引入过度繁琐的弹药负担，可先采用普通箭矢默认充足、特殊箭矢消耗制。

## 4. 武器随机词条按类别适配

- 弓：射程、拉弓速度、暴击、穿透、元素箭伤害。
- 弩：装填速度、破甲、暴击伤害、穿透。
- 匕首：攻速、暴击、背击、吸血。
- 长枪：突刺距离、穿透、击退、对大型魔物伤害。
- 双手剑/斧/锤：攻击力、破甲、范围、硬直。
- 法杖/魔杖：法术强度、元素增伤、法力消耗降低、冷却缩短。
- 盾牌：格挡率、格挡减伤、异常抗性、反击。
- 所有词条都必须有明确实际效果；没有对应战斗机制的词条不得生成。

## 5. 远程战斗 AI 与公平性

- 敌方弓手、法师也可以远程攻击玩家，不能只给玩家单方面优势。
- 怪物需有可读的攻击预警、弹道或范围提示，玩家可通过走位、掩体、闪避或防御应对。
- 投射物必须有生命周期、最大射程和碰撞过滤，避免穿墙、重复命中或离屏无限存在。
- 远程武器的DPS需综合射程、安全距离、攻速、弹药和技能消耗平衡，不能简单比近战伤害高。
- Boss/精英怪应有适当远程应对方式，避免被无风险风筝。

## 6. 首版范围控制（MVP）

首个可玩改造版本优先实现：
1. 单手剑、双手剑、匕首、长枪、斧。
2. 短弓、长弓、弩。
3. 法杖、魔杖。
4. 战士、游侠、法师三个基础职业。
5. 玩家与怪物的远程投射物。
6. 武器攻击距离、攻速、前后摇和命中判定。
7. 装备后真实改变属性、动画/外观和攻击行为。

盾牌、投掷武器、牧师、刺客专精、特殊箭矢、召唤师等列入后续迭代，不阻塞首版。

## 7. 验收标准

- 装备弓后角色执行拉弓/射箭动作，箭矢飞行并命中目标。
- 弓箭射程显著大于短剑；目标超出射程时无法命中。
- 弩的装填/攻击节奏与弓不同。
- 长枪攻击距离大于短剑，且有突刺动作。
- 双手武器攻速较慢但单次伤害更高。
- 法杖/魔杖释放真实法术投射物或范围效果，并正确扣除法力/触发冷却。
- 远程怪物能攻击玩家，玩家可通过移动或掩体躲避。
- 武器随机词条与武器类别匹配，词条实际改变战斗结果。
- 更换武器后，属性、攻击动作、射程、攻速和战斗反馈同步更新。
- 存档重启后装备、弹药/资源和武器词条保持一致。

## 实施边界

这是设计规范，不代表上述武器和职业已在当前分支实现。实施前必须审计 Source of Mana 的职业、武器、动画、投射物、伤害和服务器同步架构；优先复用已有机制，按 MVP 分阶段接入，避免一次性重写整套战斗系统。
