# 第一轮开发：刷怪掉落与装备成长闭环

状态：开发分支已建立；本文件是本轮实施基线。未通过构建与实机测试前，不标记功能完成。

## 产品目标

先做出一个可重复游玩的短循环：

进入灰牙森林 → 击败史莱姆/野狼/哥布林 → 获得铜币、材料或装备 → 在背包查看/使用/穿戴 → 装备属性真实改变 → 挑战精英怪 → 有机会获得更高品质装备 → 保存并重新进入后数据仍在。

不在本轮扩展国家政治、复杂阵营或大段剧情。

## 已审计的上游机制（代码现状）

- 怪物数据使用 `EntityData` Resource；包含 `_stats`、`_skills`、`_drops`、`_isBoss` 等字段。
- `MonsterAgent.Killed()` 已执行经验结算，并根据怪物数据的 `_drops` 字典把配置的物品从怪物库存掉落到地面。
- `WorldDrop` 已处理地面掉落、拾取距离、背包容量和掉落消失计时。
- `ActorInventory` 已有物品堆叠、使用、装备、卸下、导入/导出存档的基础逻辑。
- `ItemCell` 已支持装备槽、属性修正、可使用标记、图标、描述和买卖价格。
- 因此第一轮优先复用现有掉落与装备机制，不另造平行背包或掉落系统。

## 本轮只做四项

### 1. 新手区基础掉落

首批魔物：
- 森林史莱姆：黏液、少量铜币；极低概率掉落基础饰品/装备。
- 灰牙兔/幼年野狼：肉、皮、牙、少量铜币。
- 哥布林：粗制武器材料、破旧装备、铜币。
- 精英冰霜狼/火烈狼：提高装备掉落权重，加入专属材料和专属装备候选。

每只魔物的掉落表分成：常规材料、铜币、装备、稀有专属物。普通怪主要供给基础材料；精英怪提高装备掉落机会，但品质和词条仍随机。

### 2. 装备成长

首批装备部位：主手武器、头部、胸部、腿部、手部、脚部、饰品。

首批品质：普通、优秀、精良、稀有、史诗、传说。首轮实际掉落先开放普通至稀有；史诗/传说只留给后续精英/BOSS测试，避免新手区数值失控。

同模板装备的基础数值允许小幅浮动。词条按部位筛选：
- 武器：攻击、暴击、攻速、破甲、吸血。
- 防具：生命、防御、闪避、抗性。
- 饰品：暴击、经验、金币、资源恢复等。

注意：当前上游 `Item` 结构仅持有物品 ID、customfield 和数量；随机词条若要持久化，必须先设计兼容的 customfield/装备实例序列化方案，不能只在客户端临时改显示数值。本轮先验证基础装备穿戴与属性修正，再接随机词条实例化。

### 3. 背包与穿戴验收

必须实测：
- 拾取后数量增加；背包满时不丢物品。
- 可使用药剂：真实扣除1个并应用效果。
- 可穿戴装备：正确替换同部位旧装备。
- 卸下装备：属性回退。
- 装备穿戴前后角色面板数值正确变化。
- 退出/重进后背包、装备和属性一致。
- 连续拾取同类可堆叠材料时数量正确。

### 4. 中文与动漫风表现

玩家可见的首批内容使用简体中文：森林史莱姆、灰牙兔、幼年野狼、哥布林、冰霜狼、火烈狼；物品名称、描述、掉落提示和装备品质同步中文。
保留内部资源名、ID、路径，避免破坏数据库哈希与存档兼容。
美术采用现有可合法复用的对应素材；没有真实狼/蜥蜴人素材时，不把不相干图片冒充对应怪物。先完成可识别的史莱姆、哥布林等，再补齐狼类素材。

## 明确不做

- 本轮不批量接入450种怪物、420件武器。
- 不做复杂公会政治、国家关系和多结局剧情。
- 不做多人职业平衡。
- 不做没有实际效果的套装/词条UI。
- 不声称随机词条、套装或存档已完成，除非服务端权威数据与读档验证通过。

## 开发顺序

1. 追踪服务端怪物掉落、物品拾取、装备属性修正和存档写入路径。
2. 为新手区选定真实存在的怪物素材与物品图标，核对授权和资源引用。
3. 接入第一组中文怪物/物品/装备数据与掉落表。
4. 构建 Android 测试包。
5. 执行拾取、装备、卸下、重启读档和精英掉落测试。
6. 根据实测结果再扩展随机词条和套装实例。

## 本轮验收定义

只有在 Android 构建成功并通过以下测试后才算交付：
- 普通怪掉落材料与铜币。
- 精英怪装备掉落率高于普通怪，且掉落来源可识别。
- 玩家可以拾取、使用、穿戴、卸下。
- 装备实际改变角色属性。
- 重启后背包和装备不丢失。
- 玩家可见文本无英文残留（本轮涉及的界面与内容范围内）。
