# 精英装备掉落与随机词条系统

适用项目：夏叶的异世界冒险（Eternal World）
开发分支：ew/mobile-first
状态：设计规则，待接入实际掉落代码与实机测试

## 设计目标

精英怪应当是装备获取的主要来源之一。击败精英怪时，玩家应当较高概率获得装备；惊喜来自装备品质、基础属性浮动和随机词条，而不是把掉落率压得很低。相同名称、相同部位的装备也可能有不同数值和词条。

## 1. 掉落规则（初始平衡建议）

以下为首轮测试参数，不是最终固定值，需通过实际刷怪节奏测试调整：

- 普通怪：装备掉落概率低，主要提供铜币和基础材料。
- 强化怪：有小概率掉落普通/优良装备。
- 精英怪：每次击杀至少进行一次装备掉落判定；装备总掉落概率建议 65%–80%。可按精英等级、区域危险度调整。
- 精英队长：装备总掉落概率建议 85%–100%，并提高稀有品质与专属词条权重。
- 区域首领：至少掉落一件符合当前区域进度的装备或专属制作材料；稀有装备仍保留随机性。

装备概率与品质概率分开计算。高装备掉落率不等于高品质装备必掉。不得让低等级精英稳定产出远超玩家阶段的装备。

## 2. 品质与数值浮动

品质建议：普通、优良、精良、稀有、史诗、传说。

每件装备生成时按顺序确定：
1. 装备类别与部位；
2. 装备模板和适用等级区间；
3. 品质；
4. 基础属性浮动；
5. 随机词条数量与词条内容；
6. 专属掉落标记（若来自特定精英/首领）。

同一模板的属性在合理区间内波动。建议初始基础属性浮动：
- 普通：模板值的 90%–105%
- 优良：95%–110%
- 精良：100%–115%
- 稀有：105%–120%
- 史诗：110%–130%
- 传说：115%–140%

数值区间只是首轮调参起点；最终应按物品等级、部位和属性预算归一化，避免高品质乘数叠加后失控。

## 3. 武器随机词条

武器可随机生成前缀/后缀词条。词条必须与武器类别、角色战斗机制相容。

词条例子：
- 锋锐：增加物理攻击。
- 迅捷：缩短攻击间隔（设置上限）。
- 破甲：攻击时部分无视目标护甲。
- 吸血：按实际造成伤害回复少量生命（设置触发冷却和上限）。
- 猎魔：对魔物造成额外伤害。
- 坚定：增加格挡/抗打断能力（仅适用于支持该机制的武器）。
- 精准：增加命中或暴击属性（若战斗系统有对应判定）。

防具、饰品使用各自词条池，例如生命、护甲、抗性、移动、魔力、异常状态抗性。不能给所有装备无差别套用同一词条池。

## 4. 随机性、公平性与防止数值膨胀

- 词条数量由品质决定，但品质不保证每条都是最优词条。
- 同一装备可以出现不同组合；词条数值也有小幅浮动。
- 设置词条权重、互斥组和属性上限，避免多个强力词条无限叠加。
- 精英专属装备应有辨识度，但不是每次都出毕业装。
- 装备等级/需求等级限制应与区域进度匹配。
- 保留装备来源、品质、词条和生成种子/记录，便于复现问题与存档兼容。
- 不能通过纯客户端随机生成决定权威掉落；若沿用 Source of Mana 的服务器权威架构，掉落生成应由权威端执行并同步结果。

## 5. UI 与玩家反馈

掉落时显示：
- 装备名称与品质颜色；
- 装备部位、需求等级；
- 攻击/防御等基础属性；
- 每条随机词条及具体数值；
- 掉落来源（精英怪名称/区域）。

背包和装备比较界面应显示相对当前装备的属性变化；装备后必须真实改变角色战斗数值，若项目支持纸娃娃/装备外观，也应同步显示。

## 6. 验收测试

- 连续击杀精英怪进行至少 1000 次模拟，检查装备掉落率是否落在配置区间。
- 检查同模板装备是否产生不同基础属性和词条组合。
- 检查词条与武器/防具部位兼容，不出现无效或无法触发的词条。
- 检查装备穿戴、卸下、死亡/重连、存档读取后属性一致。
- 检查精英怪装备强度不会明显越过角色当前区域成长曲线。
- 检查普通怪、精英、队长和首领的掉落价值层次清晰。

## 7. 实施边界

本文件只记录系统设计，不代表随机掉落、词条或UI已经在游戏中实现。接入前必须审计 Source of Mana 现有物品数据结构、掉落权威端和装备属性计算路径，避免重复造系统或破坏原有联网同步。
